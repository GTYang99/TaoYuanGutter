# Requirement

## Background
- 側溝表單的「補充說明」目前僅能手動輸入文字。
- 現場填寫時常使用花圃、焊接、車擋、水泥封邊與螺絲固定等固定描述，需求希望以膠囊快速填入。

## Goal
- 在備註欄加入五個可點擊的預設內容膠囊，讓使用者能快速填寫常用備註，同時保留自由文字輸入。

## Functional Requirements
- 在側溝表單的備註欄提供五個膠囊：花圃、焊接、車擋、水泥封邊、螺絲固定。
- 使用者可點擊膠囊，將對應預設內容附加至備註欄；多個內容以中文逗號「，」分隔。
- 同一預設內容在同一份備註中只能加入一次；再次點擊不得產生重複文字。
- 備註欄仍可手動輸入、編輯其他資訊。
- 預設內容與手動輸入的結果必須沿用既有 `NODE_NOTE` 表單、草稿與提交流程。

## Non-functional Requirements
- 使用既有 Android Kotlin、ViewBinding 與 Material Components；不得引入新的 UI 框架。
- 不變更後端 API、`NODE_NOTE` 欄位名稱、草稿資料格式或既有表單驗證規則。
- 可編輯、檢視、匯入鎖定與虛擬點模式的互動限制須保持一致。

## Acceptance Criteria
- AC-001：可編輯的側溝表單在備註欄附近顯示五個內容正確的預設備註膠囊：花圃、焊接、車擋、水泥封邊、螺絲固定。
- AC-002：使用者點擊任一膠囊後，該預設內容會附加至備註欄；與已有內容以中文逗號「，」分隔，且相同預設內容不會重複加入，使用者仍可繼續手動編輯。
- AC-003：填入後的備註會透過既有 `NODE_NOTE` 收集、草稿保存、表單重建與送出流程保留，且不新增或變更 API 欄位。
- AC-004：檢視模式、匯入鎖定、虛擬點模式與既有備註欄的顯示／可編輯限制不回歸。
