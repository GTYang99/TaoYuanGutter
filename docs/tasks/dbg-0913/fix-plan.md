# Follow-up Fix Plan: ISS-DBG-0913-004

## Failed Behavior
- 返回表單時，側溝形式、位置、測量座標編號或溝蓋板厚度空白，未必顯示「尚未填寫完畢」。
- 明溝會跳過不應免填的細節欄位。

## Minimum Fix
1. 在 `validateRequiredFields()` 的虛擬點分支後，驗證所有非虛擬點皆需要的側溝形式、位置與測量座標編號。
2. 只讓無法開蓋跳過細節欄位；明溝只跳過溝蓋板厚度。
3. 以 Android UI 回歸測試驗證各新增欄位、明溝細節欄位與無法開蓋識別欄位的返回 Alert。

## Regression Risk
- 共用驗證同時供送出與返回流程使用；測試須涵蓋返回 Alert，並由既有送出流程共用相同規則。
