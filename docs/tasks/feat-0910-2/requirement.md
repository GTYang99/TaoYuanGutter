# Requirement

## Background
- 側溝資料填寫表單的欄位順序與拍照按鈕名稱需要依最新 UI 規格調整。

## Goal
- 讓新增與編輯表單依指定順序呈現完整欄位，並為新建表單提供指定的破損與淤積預設選項。

## Functional Requirements
- 新增「測量狀態」欄位，並將「待架站」與「無法開蓋」移入該欄位。
- 將欄位（標題與其輸入控制項／照片區塊一起）依序排列為：測量狀態、測量座標編號、側溝位置、截面形式、測量位置及側溝概況、側溝測量深度照片、側溝測量深度（公分）、溝蓋板厚度（公分）、側溝頂寬度照片、側溝頂寬度（公分）、側溝材質、溝體結構受損、附掛或過路管線、淤積程度、補充說明。
- 新建表單的「淤積程度」預設為「無」，「溝體結構受損」預設為「否」。既有資料、匯入資料與草稿應保留其原有選取值。
- 將拍照按鈕文字改為「拍攝照片（概況）」、「拍攝照片（深度）」與「拍攝照片（寬度）」。

## Non-functional Requirements
- 不變更後端 API contract、欄位 key、照片 slot／上傳 metadata、驗證、草稿、匯入鎖定、檢視與虛擬點行為。
- Planning 不修改 production code；不降低 acceptance criteria；不略過測試。

## Acceptance Criteria
- AC-001：新增／編輯表單顯示「測量狀態」，其中包含「待架站」與「無法開蓋」。
- AC-002：所有指定欄位的標題與對應控制項依需求所列順序完整呈現。
- AC-003：新建表單的「淤積程度」預設為「無」，「溝體結構受損」預設為「否」。
- AC-004：既有資料、匯入資料及草稿的破損與淤積值不會被新建預設值覆寫。
- AC-005：三個拍照按鈕分別顯示「拍攝照片（概況）」、「拍攝照片（深度）」與「拍攝照片（寬度）」。
- AC-006：欄位資料收集、驗證、照片 slot／上傳、無法開蓋、待架站、匯入鎖定、檢視與虛擬點既有行為維持不變。

## Constraints
- 僅調整本任務涵蓋的表單 UI、初始化與測試；不進行無關重構。
- 「截面形式」在需求中列為排序項目；除非 UI 規格另有明確文字要求，既有顯示名稱不在本任務變更範圍。
