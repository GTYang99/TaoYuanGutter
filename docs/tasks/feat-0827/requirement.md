## Function 點擊功能
### "設定"按鈕
- 跳出選項框，對API組別選項提供複選功能
- 使用者選擇內容後，"調查長度"下方依照使用者選擇內容重新顯示顯示框2數量，顯示框2大小均一致，橫向排2個，依序向下排

### "篩選"按鈕
- 點擊"篩選"按鈕後，新跳出的選項頁面
- 選項1標題"日期區間（起訖）"，下方兩個選項框。上方"請選擇開始日期"，下方"請選擇結束日期"，點擊後出現日期選項提供選擇，並填入API中
- 選項2標題"月份範圍"，下方一個選項框。"請選擇月份"，點擊後出現年、月份選項提供選擇，並填入API中
- 僅只有一個方法能進行篩選

### "顯示框1"
- 使用者點擊各組別後，由下方顯示帳號+公里數內容

### "全部組別"按鈕
- 使用者點擊按鈕後（單選），下方顯示組別選項，由API提供，並且包含"全部組別"選項
- 點擊"完成"後，"調查進度與狀態"內容均按照選擇內容顯示

## 新建功能不符

3. "設定"按鈕文字顏色"#606266",按鈕大小為76*40，點擊後的選項框，選擇時icon配色為"#562ECB"
4. "篩選"按鈕文字顏色"#606266",按鈕大小為76*40，點擊後的頁面：
    + 文字顏色問題實機沒顯示
    + 標題左邊為關閉icon，不是上一頁
    + 排列方式為：
        + 選項1標題"日期區間（起訖）"標題
        + 下方垂直堆疊兩個選項框，上方place holder"請選擇開始日期"，下方place holder"請選擇結束日期"
        + 選項2標題"月份範圍"標題，下方一個選項框，place holder"請選擇月份"
        + "月份範圍"選項框點擊後顯示年+月的選項即可，不用出現日。
5. "@+id/tvLengthDetailTitle" 的 dashboard_length_detail_hint 不預先顯示，而是帳號狀態是收合在底部，當使用者點選組別時，才有底部的新頁面顯示帳號明細。該頁面將“X組帳號明細”標題左右置中，左邊提供關閉的按鈕
