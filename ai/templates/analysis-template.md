# Repository Analysis

## Specification Impact
- 列出引用的 PRD、UI、API、AST、CMP ID 與版本
- 記錄規格缺口或衝突；沒有就寫 `無`

## Current Behavior
- 目前實際行為，1~3 點

## Expected Behavior
- 需求要變成什麼，1~3 點

## Affected Modules
- 受影響的模組或檔案，條列即可

## Dependencies
- 依賴的資料、流程、元件，條列即可

## Risks
- 主要風險，條列即可

## Unknowns
- 不確定但會影響判斷的點；沒有就寫 `無`
